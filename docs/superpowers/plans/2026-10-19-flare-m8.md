## Decisions taken by the planner (not the owner)

**D1. One state machine, ports for everything else.** `controller.rs` is a pure state machine
(`Controller::on(Event) -> Vec<Effect>`) with a clock passed in, so Prism Terminal's `dictation.ts` behaviour (begin,
stop, cancel, partials, messages, outside route, page keys, auto-warm) is tested without a window, a mic or an
engine. `dictation_ctl.rs` in `crates/flare` executes the effects on the UI thread (mic, engine, paste, view) and
feeds results back as events. The same split for `service.rs` (Prism Terminal's `dictateAnywhere.ts`).

**D2. The key reaches dictation where every key already arrives.** In the window: `AppCtl::on_key` and
`AppCtl::on_key_up` call `dictation_ctl::feed_key` FIRST (Prism Terminal's capture phase), which returns
`swallow: bool`; a swallowed key goes nowhere else. The e2e's injected keys take the same path (M10 D2), so the
`dictation` scenario's "hold Right Alt" is the real reducer. The bare Alt up that dictation swallows must not open the
window menu: `flare-win/src/sysmenu.rs` gains `swallow_next_alt_up()` that eats the next `WM_SYSKEYUP` for
`VK_MENU`/`VK_RMENU` in the existing subclass (Task 22), with a test that Alt+Space still opens the menu.
Outside the window (and inside it when the hook is the service, N9): the keyboard hook (D6).

**D3. The resident Parakeet host is a native binary, not Windows PowerShell.** Prism Terminal's
`parakeetHost.ps1` compiles C# that loads `parakeet.dll` and speaks a line protocol. Flare builds
`flare-parakeet-host.exe` from `crates/flare-dictation/src/bin/flare_parakeet_host.rs`: the same arguments, the same
stdin/stdout protocol byte for byte, the same `parakeet_full_params` layout (from `PT/core/dictation-host/parakeetHost.ps1`,
field for field, passed by value), `libloading` for `ggml.dll` and `parakeet.dll` with `SetDllDirectoryW(<engine dir>)`,
the log callback silenced. No compile cache (nothing to compile), so the `cache` argument is accepted and ignored.
The process keeps the model loaded (the point: 24 to 170 ms a pass against 0.72 to 0.86 s). It runs out of process so a
CUDA crash cannot take the app down. Recorded as DIFF-19 (PROPOSED): behaviour identical, mechanism native.

**D4. HTTPS downloads through `ureq`** (in the tree already), on the store's worker thread, streamed to `.part` in
64 KiB chunks with SHA-256 and a byte count as they arrive. No proxy configuration beyond what `ureq` reads from the
environment (Prism Terminal used Electron's `net`, which follows the system proxy: a difference only behind a proxy;
listed in Q8). Loopback HTTP to `whisper-server` is hand-written over `std::net::TcpStream` (GET `/`, POST
`/inference` multipart), no crate.

**D5. The GPU pack unzips with the `zip` crate** (O19) at a release without the three advisories, never 8.6.

**D6. The keyboard hook lives in the app, on its own thread.** Prism Terminal runs the `WH_KEYBOARD_LL` hook in a
PowerShell helper because Electron cannot; Flare is native: `keyhook.rs` starts a dedicated thread that takes the
lock file, installs the hook, pumps messages, and posts the same events Prism Terminal's helper prints (`Ready`,
`Failed`, `Waiting`, `Down{vk, front_pid}`, `Up{vk}`, `Other`, `Digit(n)`, `Esc`) to a channel the UI thread drains.
The callback does no allocation and no I/O beyond a channel send (a low-level hook must answer within the system's
timeout or Windows removes it). Recorded as part of DIFF-19 (same behaviour, native mechanism).

**D7. Voice processing.** Chromium's `getUserMedia` gave Prism Terminal WebRTC echo cancellation and auto gain.
Flare captures through WASAPI shared mode with `AudioCategory_Communications` set by `IAudioClient2::SetClientProperties`
(Windows then applies the device's communications processing, which on most devices includes echo cancellation and
gain), and on Windows 11 22H2+ names the default render endpoint as the echo reference through
`IAcousticEchoCancellationControl` when the capture endpoint offers it. Noise suppression is not requested. Recorded as
DIFF-18 (PROPOSED); the cue leaking into a clip (O13) goes on the owner's hands-on list.

**D8. Copy names on the link.** `copy_name(exe)`: the packaged app (`flare_win::packaged::is_packaged()`) is
"Flare", any other build "Flare (Dev)"; a second copy of the same name is numbered by the service: "Flare (2)"
(N27). Prism Terminal's "Stable" kind has no Flare twin.

**D9. The orchestrator is not in Flare** (it is #244's agent feature, not dictation). Wherever Prism Terminal asks
"is the orchestrator ACTIVE", Flare answers no: every heard text with no Flare window in front goes to the picker.
`SendTab.orchestrator` exists and is always false, so a later port of the orchestrator is one switch. The tooltip of
"Dictate from any app" drops its orchestrator clause. Recorded as DIFF-16 (PROPOSED), Q1.

**D10. The fixture cache is filled by a command, never by a test.** `cargo e2e -- --fetch-fixtures` downloads
`ggml-tiny.bin`, `jfk.wav` and the Parakeet q4 file into `tools/e2e/.e2e-cache` (gitignored) with their pinned hashes
(Task 28); a scenario whose fixture is missing fails with "run `cargo e2e -- --fetch-fixtures` first", never fetches.
The orchestrator runs that command once before Wave 5 (Q7). `vendor/whisper` comes from `tools/fetch-whisper.ps1`, run
once by the orchestrator before Task 29 (Q7).

**D11. The engine never stands down while dictation is on** (N5, Prism Terminal passes `idleMs: Infinity`): Flare
is an app with the dictation service, not Prism. `EngineConfig::idle` is `Option<Duration>`; Flare passes `None`; the
300000 ms default and its tests stay for completeness (rule 95 amended, Task 34).

**D12. Parity file edits happen twice and only by Tasks 2 and 36.** Task 2 writes the new and amended lines (open)
and the new difference rows (PROPOSED); Task 36 ticks every M8 line after the green run. No other task edits
`docs/parity.md`.

**D13. The models card's wording.** O14 gives Flare its own models folder, so "Shared by both apps on this PC." and
"Prism and Prism Terminal share it." would be untrue. Flare: models sub "Downloaded once, kept on this PC." (six
words); no tag on the models card; Uninstall title "Delete <what> from this PC." Recorded as DIFF-17 (PROPOSED), Q3.
