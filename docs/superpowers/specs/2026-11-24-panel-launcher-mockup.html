Panel launcher: a way into the side panel while it is closed

Each tab has its own launcher, because the panel is per tab. It only shows while that tab's panel is closed, and disappears the moment the panel opens. Pick a placement, then click through: Browser, Device, and Open file (a 3D model here). The panel header gets an Open in button.

Move the pointer onto the dock in the top right: it turns solid. Off it, it is 32% so the text under it still reads.

A · Corner dock

  • Where: the tab's top right, where the panel would open. Four icon buttons, each with a tooltip.
  • Idle: 32% so the terminal text under it stays readable. On hover or keyboard focus it is solid.
  • Plus: always findable, one click. Minus: it still sits over the top-right characters of the grid.

B · Edge slide-out

  • Where: a thin handle on the right edge. Near the edge (56 px) the rail slides out with labels.
  • Idle: only the handle shows, so it covers no text at all. Same feel as the collapsed sidebar.
  • Plus: nothing in the way, room for labels. Minus: less discoverable, and the right edge is also where the scrollbar lives.

Open in (panel header)

  • A file (image, text, 3D model): "Open in" hands it to the system's default app for that type.
  • A web page: "Open in browser" opens the same address in the default browser (Zen here).
  • Device panel: no Open in (nothing outside Flare shows it).
